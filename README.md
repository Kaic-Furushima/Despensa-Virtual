# Despensa Virtual

Aplicação web para controlar os alimentos da despensa de casa, avisar sobre produtos perto do vencimento e sugerir receitas, ajudando a reduzir o desperdício.

**Acesse:** https://kaic-furushima.github.io/Despensa-Virtual/

Basta criar uma conta com e-mail e senha para começar a usar.

## Funcionalidades

- Cadastro, login e recuperação de senha
- Cadastro de alimentos com nome, quantidade e data de validade
- Lista em tempo real, ordenada por validade, com busca
- Edição, consumo de uma unidade e exclusão de itens
- Alertas de alimentos que vencem em até 7 dias e de alimentos já vencidos
- Sugestão de receitas com base no que há na despensa

## Tecnologias

HTML, CSS, JavaScript, Bootstrap 5 e Firebase (Authentication e Firestore).
